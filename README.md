Mario Kart eBay Auction Pricing Analysis | R, Data Analysis, Inferential Statistics

Conducted statistical hypothesis testing in R on $N=141$ eBay auction listings to identify key drivers of final sale price using Welch’s $t$-tests and Two-Way ANOVA.

Proved that wheel inclusion ($\Delta = +\$11.45, p < 0.001$) and stock photos ($\Delta = +\$4.17, p = 0.0076$) independently boost auction revenue, while finding no significant interaction effect ($p = 0.174$).

Evaluated parametric assumptions using Shapiro-Wilk normality tests and applied the Central Limit Theorem ($n \ge 30$) to ensure test robustness; visualized price distributions using ggplot2.
